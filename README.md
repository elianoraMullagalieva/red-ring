# Кольцо карточек — красная версия

Самостоятельный блок первого экрана: 3D-кольцо из пятнадцати живых карточек на красном фоне с паттерном.
Кольцо плывёт само, крутится мышью и пальцем, к краям дуги карточки тают. Без фреймворков: Vite + TypeScript + CSS.

```bash
npm i
npm run dev     # http://localhost:5181/red-ring/
npm run build   # dist/
```

Логика кольца — `src/ring.ts`, содержимое карточек — `src/cards.ts`, оформление — `src/style.css`.
